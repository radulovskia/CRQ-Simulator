Attack Vectors

Upload a .csv or .xlsx file with these columns: Vector ID, Attack Vector, ATT&CK Technique Chain, Terminal Tactic, Loss Event Type, Requires Exploitable Vulnerability, Requires Internet Facing, ATT&CK Mitigations, Base Threat Event Frequency Min, Base Threat Event Frequency Mode, Base Threat Event Frequency Max, Base Susceptibility Min, Base Susceptibility Mode, Base Susceptibility Max, Typical Outage Hours Min, Typical Outage Hours Mode, Typical Outage Hours Max, and Reference.

Join technique IDs with ->, for example T1190 -> T1059 -> T1486. Terminal Tactic is Impact, Exfiltration, or Collection. Loss Event Type is Availability, Confidentiality, Integrity, or Fraud. Requires Exploitable Vulnerability and Requires Internet Facing are Yes or No. Base Threat Event Frequency Max must be greater than Base Threat Event Frequency Min. Each susceptibility is from 0 to 1, and Base Susceptibility Max must be greater than 0. ATT&CK Mitigations are optional comma-separated IDs such as M1050.
