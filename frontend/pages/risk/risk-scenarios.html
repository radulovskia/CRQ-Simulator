Risk Scenarios

Upload a .csv or .xlsx file with these columns: Scenario ID, Scenario, Threat Actor ID, Attack Vector ID, Target Type, Target ID, Risk Owner Organisational Unit ID, Description, Status, Threat Event Frequency Min, Threat Event Frequency Mode, Threat Event Frequency Max, Threat Event Frequency Basis, Susceptibility Min, Susceptibility Mode, Susceptibility Max, Susceptibility Basis, Max Loss Events per Year, Frequency Lambda, Response Min, Response Mode, Response Max, Replacement Min, Replacement Mode, Replacement Max, Productivity Min, Productivity Mode, Productivity Max, Secondary Loss Probability, Fines Min, Fines Mode, Fines Max, Reputation Min, Reputation Mode, Reputation Max, Competitive Min, Competitive Mode, Competitive Max, Magnitude Basis, Magnitude Lambda, Evidence, and Calibration Notes.

Every numeric cell is required; a blank is rejected rather than stored as zero. Target Type is Software System or Business Process. Status is Draft, Reviewed, or Approved. Threat Event Frequency Basis, Susceptibility Basis, and Magnitude Basis are External, Internal, Expert, or Mixed. Frequency Lambda and Magnitude Lambda are from 1 to 10. Susceptibility and Secondary Loss Probability are from 0 to 1. Max Loss Events per Year must be greater than Threat Event Frequency Min multiplied by Susceptibility Min. Threat Actor ID, Attack Vector ID, Target ID, and Risk Owner Organisational Unit ID must already exist.

Suggest and Simulate

ActionWhat happens
Suggest Opens the form and fills it from the actor, attack vector, target, vulnerability findings, and Settings. The proposal table shows each number and its reason. A withheld row names the missing fields and keeps the current cell values. Save stores the worksheet.
Simulate Opens the charts for 10,000 years of the saved worksheet, with Implemented controls and seed 1. The run reads that saved worksheet. A current control that eliminates the scenario refuses the run.

Proposals

Filled rows are copied into the open form. A triple is minimum / mode / maximum. A withheld row keeps the current values. Save stores the worksheet.
